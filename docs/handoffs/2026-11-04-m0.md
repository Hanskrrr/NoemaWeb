## Changed from the plan (please confirm)

- **Stack.** Node built-ins replace Hono, better-sqlite3 and Vitest (ADR 0002). Our own client replaces the AI SDK (ADR 0003). Our own renderer replaces Streamdown, because anchors need a character-level source map (ADR 0004). Each sits behind one module or interface and can be reversed.
- **Repository.** The repository is NoemaWeb rather than `noema-app/`, cloned at `NoemaLearningNote/NoemaWeb`.

## Known gaps

- `node:sqlite` is not yet stable in Node (see ADR 0002).
- The web bundle is about 600 KB minified, mostly React and KaTeX. Lazy-loading KaTeX is in ideas.md.
- GFM tables are not rendered as tables yet.
- A character reference such as `&amp;` maps to its first raw character only.
- Spike pins live in localStorage. Real anchors are stored from M2.
- Decisions still open from the brief: the hero case, the provider and a monthly cap, the UI words, and putting `NoemaLearningNote/` under Git.
