# Handoff 2026-11-12: PDF pages, and the page sent to the model

PDFs now work in the app on the founder's Mac. His verdict on text only: "kinda disappointing". Other tools show the whole PDF, pictures included, and their model sees it. He chose to always send the page to the model with a question about a PDF passage. Decisions are in [ADR 0022](../adr/0022-pdf-pages-and-pictures.md).

## What changed

- **A PDF opens as its pages.**
  - pdf.js draws each page in the reading pane, so figures, formulas and layout show as printed.
  - pdf.js's text layer lies on top, so text is selected on the page itself.
  - **Pages / Text** switches to the stored text.
  - Selecting on a page works as in text: **Ask about this**, **Pin**, marks for what was asked (on the page and in the margin), Back to the passage, and search landing on the page with the words marked.
- **The page goes to the model.**
  - Choosing a passage of a PDF to ask about draws its page as a picture, about 1,600 pixels on the longer side, and keeps it once per page.
  - Every question about that passage, side questions included, sends it before the text.
  - **What was sent** shows the picture.
  - If a model refuses pictures, the question is asked again at once with text only, and that model gets text only after that.
- **How selection maps to the text.**
  - Core's `pdfToMarkdown` records which pdf.js item each character of the Markdown came from.
  - The browser reads the same items with the same pdf.js, which it loads from the server's copy. It checks that it gets the stored text exactly, then uses the map.
  - The Markdown is unchanged, so PDFs already added get pages without being read again.
- **Server.**
  - `/api/pdfjs/...` serves pdf.js and its character maps, fonts and fallback decoders, and nothing else from that folder.
  - `PUT /api/sources/:id/versions/:v/pages/:n/image` keeps a page picture, `GET /api/page-images/:v/:n` serves it, and migration 015 adds `source_page_image`.
  - The stored request names pictures by reference, never their bytes.
- **Fixture:** `figure-slides.pdf`, a made-up two-slide deck with a chart.
