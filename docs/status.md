# Status

Where the v0.1 prototype stands. Last updated 2026-11-21. The milestones come from the prototype brief, which lives with the product thinking in the founder's `NoemaLearningNote` workspace. Each session's details are in [`handoffs/`](handoffs/), the decisions in [`adr/`](adr/).

## Milestones

| Milestone | State | What it gives |
| --- | --- | --- |
| M0 Setup | Done | The repository, the fake model, the app shell, tests that run from a clean clone |
| M1 Chat that survives | Done | Answers stream and survive reloads and crashes, with tables, math and code; connect a model with your own key from the app |
| M2 Branch and return | Done | Ask a side question about any selected passage and go Back to that exact passage; make a side question its own thread, or merge what it found back in (nothing already said is rewritten); cut a thread that drifted into a new thread at a question, and join it back; titles the model writes and you can change |
| M3 Sources | Done | Add a web page (an arXiv paper is read from its HTML version), a PDF, or pasted text; it opens in a reading pane with the conversation beside it; ask about any passage, and Back returns to it; passages asked about are marked, darker where you asked more; a page read again keeps what you asked with the version you asked it about |
| M4 Find again | Done | ⌘K search over everything, in English or Chinese, landing on the exact message, note block or passage; reopening where you were; side questions you never came back from; a map of each thread, each exchange labelled by what it established; catalogs for long threads and notes |
| M5 Context you can see | Done | **What was sent** under every answer, part by part and word for word; **About you**, sent with every question; **pins**: passages sent with every question in a thread and its side questions until unpinned; **Ask again**: a new answer, with every earlier one kept and the side questions asked from it still leading back; **Export** as JSON (imports into an empty Noema, the same table by table) or as Markdown to read. Memory beyond About you is being discussed |
| M6 Dogfood | Next | Two weeks of real use with course material and the diary, then three classmates for a week |

Also built along the way: **the Assistant** (ADR 0023), one assistant for the whole notebook at the top of the sidebar: it looks things up across threads, sources and notes before it answers (read-only), shows each lookup as it goes, cites with labels that open the exact message, passage or note, and a light around the window shows it listening, thinking, looking and writing (step 1 of 4: memory, background jobs and noticing on its own are not built); since ADR 0024 it is with whatever is open (⌘J): since ADR 0028 it floats over it, folded to a bar with questions for the place until something is asked, moved and resized where you like, resting as its orb in the corner when put away, or pinned beside, knows what is selected, cites with cards that preview the very words it quoted, takes you places, and proposes changes (threads, notes, pins, renames, merges, the Trash, sources) that wait for Do it, with Undo; since ADR 0033 it makes the changes itself, in as many rounds as a request takes, each with Undo and Undo all (writing files on the computer still waits; "Asks first" in its header makes everything wait), and it says less: one card a thing cited, the first three, and its lookups folded; **folders on this computer** (ADR 0025): Files in the sidebar links a folder by its path and lists it like a code editor; any text file (Markdown, code) or PDF opens as a source, read again when it changed on disk; text files are edited in place; a file becomes a note and a note is saved into the folder; the Assistant lists, searches and opens files, and proposes writes and edits that wait for Do it, with Undo; **rooms** (ADR 0026): what is learnt about one subject set together, whatever kind it is: a source brings the threads asked about it and their notes, shown as one cluster on the room's map, with what was asked there and what was left open; lines only where something links two clusters; things go in by dragging onto a room, right-click, or choosing in the room; files and links dropped on Sources or a room become sources; the Assistant sees rooms and proposes putting things in one; **reading a room** (ADR 0027): on the learner's word the AI writes each thing a short summary whose key points link to the words they quote, then suggests links between things (explains, example of, builds on, contrasts with…), dashed until kept, which the learner keeps, changes, turns around, dismisses or draws by hand; the Assistant knows the room it is asked in and proposes links and taking things out; since ADR 0029, dragging from one card to another links them and the AI chooses what the line means, holding a card moves it, suggestions wait in Review, kept links are drawn in their kind's colour, and the Assistant renames, deletes and merges rooms and changes links (each confirmed); since ADR 0030, a room opens on its brief (what it adds up to, what is still open, what waits for review), its cards glow while they are read, and you ask, write a note or add a source from the room itself; a thread in a room is answered with the room's brief; since ADR 0031, asking in a room may search the web (DeepSeek's search) and offers the pages found as sources to add, and a room can find sources for what is still open in it; since ADR 0032, a room can be put in bigger rooms (in many, never inside itself): there it is a door showing what it holds and its brief, the sidebar is a tree, the way in shows above a room's name, and a bigger room's brief is written from its rooms' briefs; **ways to see a room** (ADR 0035): a switch at the top of every room between Folders (the room as Finder lists a folder: rooms inside and concepts as folders opening in place, things as files, "also in" for a thing kept in other rooms, a preview, ⌥-drag to keep in both), Concepts, Path (the order to study in, from the links kept, side by side what contrasts) and the Board (the map), remembered per room; since 2026-11-27, a room opens on an Overview (its goal, the last unfinished question, its topics), the Board groups cards by topic with a free layout on request, a card can be focused on its links, nested inside another, and resized within limits, and the Board has a density kept in the browser: Normal (summaries, counts, words on the lines) or Compact (titles and links only); **concepts** (ADR 0036): when a room is read, the AI suggests the key ideas its things are about, defined by the words of one of its things and linked by what builds on what, dashed until kept (Keep all), dismissed for good, filled by dragging, split, merged, linked by hand or made a room; since ADR 0037, **the concept-reading skill**: every piece of every thread, source and note is read once for the concepts it discusses, with the exact words and what it does with them (defines, explains, uses, gives an example, asks), and the same idea in different materials and rooms is one concept, notebook-wide; each piece is hashed, so the room says what changed since its concepts were read and Update reads only that; a concept says where it is (materials, places), which concepts share its things, and a thread, source or note shows its "Concepts here" and puts selected words under one; since ADR 0038, **concepts in levels**: only threads and notes are read for concepts (a source's words are found by search), details are left out, and the AI puts the room's concepts in a few topics, each kind or part of a concept inside it; the Concepts view shows them as cards, topic by topic, with a display lens kept in the browser: Study order (later topics folded, a topic's cards in one column in the order that came first, kinds, parts and links said in words on the card), Explore (all topics open), Audit gaps (all topics open, no relations on cards, a line counting ideas to review, materials under no concept and open questions); the most worked with first, the rest folded, with Review beside them; a concept is put under another or in a topic by its list or by dragging its card, found by name, and a concept the learner makes is filled (what it covers, what goes inside, where the materials discuss it), each waiting to be kept; a reading can be stopped; **asked before**, a reminder when a question being written in a new thread, or a side question on a passage, was already asked somewhere (words compared at once, then the chat model reading for meaning), with Open it and Ask there, and a word before writing a second note from the same thread (ADR 0020); study notes made of blocks you edit in place, with AI suggestions you accept or discard, notes split and merged, and citations that open the exchange beside the note; notes listed under the thread or source they came from; a sidebar that shows one list at a time; the Trash, with Undo and Restore; right-click on a thread, source or note (in the lists, a room or the Trash) moves it to the Trash or, after saying what goes, deletes it for good (ADR 0034).

## How it is checked

- 376 unit and integration tests (`pnpm test`) and 90 end-to-end tests (`pnpm e2e`), all with the fake model.
- The brief's acceptance tests are in the suite (see [codebase.md](codebase.md#e2e-the-app-end-to-end)).
- Tried by the founder with DeepSeek on his Mac: connecting a key, streaming answers, prompt caching, titles and headlines, and reading a real arXiv paper (over 1,600 formulas, all rendered).

## Known gaps

- `pnpm lint` (Biome) now passes with 0 errors (116 warnings); it had 37 errors that CI never ran on. `pnpm e2e` has not been run on macOS lately; CI runs it on Linux for pull requests.
- CI installs without `--frozen-lockfile`; now that `pnpm-lock.yaml` is committed, it should.
- Images in web pages are not shown (their alt text is). A PDF opens as its pages, and a question about it goes with a picture of the page (ADR 0022); its stored text has formulas as the characters drawn, and a scanned PDF has no text (ADR 0021).
- A note's citations point at an exchange, not one answer of it: after asking again, a citation shows the answer in use (ADR 0017).
- The reading pane does not mark the passages pinned from it (ADR 0019).
- An export imports only into a Noema of the same schema version, and only into an empty one (ADR 0018).
- The Assistant has been tried only with the fake model: how DeepSeek uses the lookups and the change tools (and its thinking with them), and whether it quotes exactly, is to be seen on the Mac (ADRs 0023, 0024).
- Reading a room (ADR 0027) has been used once by the founder with DeepSeek (a room of six things): six summaries and eight suggested links, which overlapped on the map; fixed the same day (ADR 0027 addendum). How good the summaries and links are, and how often quotes are word for word, is still to be judged.
- Concepts (ADRs 0036 to 0038) have been tried only with the fake model: how DeepSeek follows the concept-reading skill (quotes word for word, the same names across pieces, the judge joining the right names), whether its topics and kinds are right, and whether Find materials leaves out passing mentions, is to be seen on the Mac. The Assistant does not see concepts, they are never read in the background, and there is no page listing all of a notebook's concepts or topics. Stopping a reading is tested on the server, not in the browser.
- Rooms (ADR 0026) are tested with made-up notebooks; not yet used on the founder's own. Dragging is tested in Chromium (Playwright); Safari's drag and drop is not tried.
- Folders (ADR 0025) are tested with folders the tests make; not yet tried on the founder's own folders, or with the Assistant on DeepSeek. There is no file watching: a file changed on disk is read again when opened again.
- "Asked before" by meaning has been tried only with the fake model: how well a real model judges is to be seen in use (`pnpm asked:check` replays a notebook through it; ADR 0020).
- One notebook per install; no accounts, sync or mobile layout (out of scope for v0.1).
