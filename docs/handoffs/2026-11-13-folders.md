# Handoff 2026-11-13 (latest): folders on this computer

The founder asked whether Noema can reach a local folder, then said how: "as any other agent does". Noema opens and edits the files, and they all count as sources. Any text file (PDFs, Markdown, code) opens "like navigate in cursor or vscode". Notes can be exported into the folder, and files imported as notes. This is his decision against the fence line on imports, recorded in AGENTS.md and [ADR 0025](../adr/0025-folders-on-this-computer.md). About you is not changed: he has not yet chosen how to polish it.

## What changed

- **Files, in the sidebar.** A folder icon on the rail opens Files.
  - **+ Link a folder** takes the folder's whole path (Finder copies it with ⌥⌘C; `~` works).
  - Files lists the folder like a code editor: folders first, opened one level at a time and remembered. Hidden and generated folders (`.git`, `node_modules`, `dist`, caches, virtual environments) are left out.
  - Pictures, archives and programs are dimmed. ↻ lists again after changes on disk. × unlinks; the files stay as they are.
- **A file is a source.** Click it, and it opens in the reading pane: Markdown as it is, code as a code block in its language, a PDF as its pages. It is asked about, cited, pinned and searched like any source. Its path shows under the title. Opening it again reads it again: if it changed on disk, that is a new version, and what was asked stays with the old one.
- **Edit.** A text file has **Edit**: the file as it is on disk, saved with ⌘S. If the file changed on disk in between, the save is refused and what was typed is kept.
- **Notes in and out.**
  - **Make a note** turns a file into a note; a Markdown file's opening heading becomes the title.
  - **save to a folder** on a note writes it as Markdown: title, then blocks, without citation labels. It does not write over a file unless you say **Replace it**.
- **The Assistant and files.** It is told which folders are linked.
  - It can list a folder, find lines in files and open a file (as a source, with a label to cite).
  - It proposes four changes that wait for **Do it**: write a file, edit part of a file, save a note into a folder, make a note from a file. Each card shows the change before Do it (lines taken out in red, put in in green), and every write can be undone.
- **Safety.** Every path is resolved inside the folder: `..` and links leading out are refused. Every write keeps what it replaced, for Undo.
- **Code.**
  - New: core `files.ts`; server `files/folders.ts` and migration 018 (`folder`, `file_backup`, `source.folder_id`, `source.file_path`, `source_version.file_hash`); web `Files.tsx`.
  - Routes under `/api/notebooks/:id/folders` and `/api/folders/:id/…` (tree, open, file), plus `/api/notes/:id/save-to-folder` and `/api/notebooks/:id/notes/from-file`.
  - The Assistant's lookup loop is async now (file lookups read the disk).
- **Two flaky tests steadied.** Two Assistant tests checked events a watcher could miss if it connected late. They now ask with `[[slow]]`, so the watcher is there first.
